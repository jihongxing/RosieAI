# Rosie AI 试点许可证检查清单

> 这是工程侧试点前检查清单，不替代正式法律意见。进入商业试点前，应按实际部署版本、模型文件和第三方服务合同再次复核。

## 核心组件

| 组件 | Rosie 用途 | 当前许可证判断 | 试点动作 |
|------|------------|----------------|----------|
| jambonz | SIP / call control / listen WebSocket | GitHub 核心仓库显示 MIT；官方自托管说明要求到 licensing.jambonz.org 获取 license key，OEM/托管模式另有商业条款。 | 自托管试点前获取并保存 license key；确认仅入站接听、listen、call hook 用法在授权范围内。 |
| Pipecat | 后续实时语音 Agent pipeline | BSD-2-Clause。 | 保留 LICENSE / NOTICE；如使用 extras 依赖，继续扫描各 provider SDK。 |

| FunASR / SenseVoice | 本地 STT | FunASR 项目为 MIT；README 同时提示预训练模型受 Model License Agreement 约束。 | 记录实际 STT 模型 ID，例如 `iic/SenseVoiceSmall`，保存模型协议。 |

| Edge TTS | 当前本地 smoke / 临时 TTS | 不是开源模型路线，可能受 Microsoft 服务条款约束。 | 只用于本地验证；真实商业试点优先切到自托管 TTS。 |
| DeepSeek / OpenAI-compatible API | 云端 LLM 兜底 | 按供应商服务条款，不属于开源许可证。 | 试点前确认数据处理、日志保留和个人信息条款。 |

## 本仓库依赖扫描

运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\ops\check-third-party-licenses.ps1
```

默认输出：

```text
data\runtime\third-party-license-report.json
```

脚本会扫描：

- `services/*/requirements*.txt`
- `services/api-go/go.mod`
- 已安装 Python distributions 的 license metadata

脚本不会替代人工复核：未安装的可选依赖、模型文件、Docker 镜像、系统包和云服务合同仍需人工确认。

2026-04-30 本地扫描结果：

- Python 依赖条目：18
- Go module 条目：16
- 仍需人工复核：20
- 报告路径：`data/runtime/third-party-license-report.json`

仍需复核的项目主要是 Go modules 缺少本地 license metadata、可选语音依赖未安装、以及模型/服务类组件需要按实际部署版本记录模型卡或商用条款。

## 上线前最低要求

- 所有生产部署组件都有明确 license 或商业合同记录。
- 所有模型文件都有模型卡或 LICENSE 链接。
- 商家声音克隆必须有授权记录；没有授权时只能使用通用合成音色。
- 不把 Edge TTS smoke 路线作为商业默认路线。
- 在发布包或运维目录中保留第三方 LICENSE / NOTICE 文件清单。
