# 文档一：Rosie AI 智能语音接线员 PRD（产品需求文档）

**版本：** v1.0 (MVP) **定位：** 线下小微商家的虚拟前台，7*24小时不接听、定预约、记笔记，零安装负担。

## 1. 核心痛点

- **漏接：** 忙时、非营业时间漏掉潜客电话。
    
- **低效：** 老板边干活边接电话（如理发师、修理工），打断工作。
    
- **反感软件：** 老板不想下App，不想学复杂的CRM，更不想盯着后台看。
    

## 2. 目标用户

线下实体店老板（美发店、牙医诊所、宠物店、餐厅、搬家/开锁公司）。

## 3. 核心功能（MVP范围）

### 3.1 语音智能接听

- **全天候接入：** 商家将手机/座机设置呼叫转移至 Rosie 专属号码。
    
- **极速对话：** AI 具备毫秒级响应，模拟真人语调（带点人情味）。
    
- **知识库对答：** 商家只需输入一段纯文字描述（店名、营业时间、服务价格、常见问题），AI 自动对答。
    
- **意图识别：** 识别用户是“咨询”、“预约”还是“投诉”。
    

### 3.2 自动化预约闭环（核心闭环）

- **规则设定：** 商家设定可预约时间（如：周六周日不预约）。
    
- **日程写入：** 自动记录预约人手机、时间、项目，并写进商家的“在线日历/表格”。
    
- **确认短信：** 挂断后自动给客户发确认信息。
    
- **摘要笔记：** 每通电话后给老板发一条极简摘要（微信或短信）。
    

### 3.3 应急转接

- **转接人工：** 遇到紧急情况（愤怒投诉、大客户）或AI无法识别的深度需求，自动拨通老板电话进行人工转接。
    

## 4. 用户流程 (The "Zero-App" Experience)

1. **极简配置：** 老板在网页填下：店名、业务范围、可预约时间、手机号。
    
2. **号码托管：** 老板拨打一个运营商指令码（如 `67*虚拟号#`）完成呼叫转移。
    
3. **自动运行：** Rosie 开始上班。
    
4. **结果交付：** 老板每天只需要看飞书/腾讯文档的一个表格，或者看微信通知。
