## 二、自建通信网关核心方案

### 方案：FreeSWITCH + SIP中继 + 虚拟号码池

**技术栈：**
- **软交换机：** FreeSWITCH（开源，免费，工业级稳定）
- **通信协议：** SIP（Session Initiation Protocol）
- **号码来源：** 170/171虚拟运营商号段批量采购
- **接入方式：** SIP Trunk（按并发计费，不按分钟）

```
    ↓
[通话结束，触发后续流程]
```

### 4.2 SIP Trunk对接（关键！）

**什么是SIP Trunk？**
- 传统电话线的互联网版本
- 运营商提供SIP账号，你的FreeSWITCH通过SIP协议连接
- **计费模式：按并发路数，不按通话时长！**

**国内SIP Trunk供应商：**

| 供应商 | 并发路数计费 | 号码月租 | 接听费 |
|--------|------------|---------|--------|
| 容联云 | 50元/路/月 | 5元/号/月 | **0元** |
| 网易云信 | 60元/路/月 | 5元/号/月 | **0元** |
| 融云 | 55元/路/月 | 5元/号/月 | **0元** |

**成本计算（以容联云为例）：**
```
3000商家，10%并发 = 300路
- 并发费：300路 × 50元 = 15,000元/月
- 号码月租：3000号 × 5元 = 15,000元/月
- 接听费：0元
- 合计：30,000元/月

单商家成本：30,000 ÷ 3000 = 10元/月
```

**等等！这还是太贵了！**

## 五、终极成本优化方案

### 5.1 号码复用技术（核心创新！）

**问题：** 为什么每个商家需要独立号码？
- 因为客户要拨打"商家专属号"
- 但其实我们可以用**一个号码服务多个商家**！

**方案：IVR按键路由**

```
客户拨打统一号码：400-XXX-XXXX
    ↓
FreeSWITCH自动接听（0成本）
    ↓
播放语音："您好，请输入商家编号"
    ↓
客户按键输入：1001（商家ID）
    ↓
路由到对应商家的AI实例
```

**成本优化：**
```
原方案：3000个号码 × 5元 = 15,000元/月
新方案：10个号码 × 5元 = 50元/月（节省99.7%！）
```

**用户体验优化：**
- 商家可以在自己的门店贴二维码："扫码保存专属号码"
- 二维码内容：`tel:400-XXX-XXXX,1001`（自动拨号+输入编号）
- 老客户第二次拨打，FreeSWITCH识别来电号码，自动路由，无需按键

### 5.2 并发路数优化

**问题：** 300路并发 × 50元 = 15,000元，还是太贵

**方案A：错峰复用**
- 观察数据：大部分商家的来电高峰不重叠
- 理发店高峰：周末下午
- 餐厅高峰：中午和晚上
- 实际并发可能只需要150路

**方案B：动态扩容**
- 与SIP Trunk供应商谈"按需计费"
- 平时购买100路，高峰时自动扩容到200路
- 类似云服务器的弹性伸缩

**方案C：自建SIP Trunk（终极方案）**
- 直接对接运营商（需要ISP/IDC资质）
- 成本降低80%
- 适合规模化后（1000+商家）

**优化后成本：**
```
- 并发费：150路 × 50元 = 7,500元/月
- 号码月租：10号 × 5元 = 50元/月
- 合计：7,550元/月

单商家成本：7,550 ÷ 3000 = 2.5元/月
```

## 七、FreeSWITCH核心配置示例

### 7.1 SIP Trunk对接配置

```xml
<!-- /etc/freeswitch/sip_profiles/external/ronglian.xml -->
<gateway name="ronglian">
  <param name="username" value="your_sip_account"/>
  <param name="password" value="your_sip_password"/>
  <param name="proxy" value="sip.ronglian.com"/>
  <param name="register" value="true"/>
  <param name="caller-id-in-from" value="true"/>
</gateway>
```

### 7.2 自动接听+IVR路由

```xml
<!-- /etc/freeswitch/dialplan/public.xml -->
<extension name="auto_answer">
  <condition field="destination_number" expression="^(400\d{7})$">
    <!-- 自动接听 -->
    <action application="answer"/>
    
    <!-- 播放欢迎语 -->
    <action application="playback" value="/sounds/welcome.wav"/>
    
    <!-- 收集商家编号（4位数字） -->
    <action application="play_and_get_digits" 
            data="4 4 3 5000 # /sounds/enter_merchant_id.wav 
                  /sounds/invalid.wav merchant_id \d+"/>
    
    <!-- 路由到对应商家的AI处理服务器 -->
    <action application="socket" 
            value="127.0.0.1:8021 async full"/>
  </condition>
</extension>
```

### 7.3 音频流转发到AI服务器

```python
# Python ESL (Event Socket Library)
import ESL

conn = ESL.ESLconnection("127.0.0.1", "8021", "ClueCon")

def handle_call(event):
    uuid = event.getHeader("Unique-ID")
    merchant_id = event.getHeader("variable_merchant_id")
    
    # 获取音频流
    conn.execute("uuid_audio_fork", f"{uuid} start /tmp/{uuid}.wav")
    
    # 转发到AI处理服务器
    ai_server = get_merchant_ai_server(merchant_id)
    stream_audio_to_ai(uuid, ai_server)
```
