## 一、5万用户的技术挑战

### 1.1 并发压力分析

**假设条件：**
- 5万用户
- 平均每人每天接10通电话
- 高峰时段（10:00-11:00, 14:00-15:00）占30%的流量
- 平均通话时长2分钟

**并发计算：**
```
日总通话量：50,000 × 10 = 500,000通
高峰时段通话量：500,000 × 30% = 150,000通
高峰小时通话量：150,000 ÷ 2小时 = 75,000通/小时
平均每分钟：75,000 ÷ 60 = 1,250通/分钟

考虑通话时长2分钟：
峰值并发 = 1,250 × 2 = 2,500路
```

**结论：** 需要支持2,500路并发通话！

### 1.2 号码资源挑战

```
5万用户 × 5元/号/月（传统价格） = 250,000元/月
仅号码成本就占收入的16.7%！
```

### 1.3 服务器成本挑战

```
单台FreeSWITCH支持500路并发
2,500路 ÷ 500 = 5台服务器
5台 × 500元 = 2,500元/月（仅FreeSWITCH）
```

### 2.2 Kamailio负载均衡

**为什么用Kamailio？**
- 专业的SIP负载均衡器
- 支持10,000+ TPS（每秒事务数）
- 可根据FreeSWITCH负载动态分配
- 开源免费

**配置示例：**
```
# kamailio.cfg
loadmodule "dispatcher.so"

# 定义FreeSWITCH集群
modparam("dispatcher", "list_file", "/etc/kamailio/dispatcher.list")
modparam("dispatcher", "flags", 2)  # 轮询算法
modparam("dispatcher", "dst_avp", "$avp(dsdst)")

# 路由逻辑
route[DISPATCH] {
    if(!ds_select_dst("1", "4")) {  # 选择可用的FreeSWITCH
        send_reply("503", "Service Unavailable");
        exit;
    }
    t_relay();
}
```

**dispatcher.list：**
```
# setid(1) FreeSWITCH集群
1 sip:freeswitch1.internal:5060
1 sip:freeswitch2.internal:5060
1 sip:freeswitch3.internal:5060
1 sip:freeswitch4.internal:5060
1 sip:freeswitch5.internal:5060
```

### 2.3 AI处理集群（关键优化）

**问题：** 5万用户，每个用户独立AI实例？不现实！

**方案：AI实例池化**

```python
# AI实例池管理器
class AIInstancePool:
    def __init__(self, pool_size=100):
        self.pool = [AIInstance() for _ in range(pool_size)]
        self.lock = asyncio.Lock()
    
    async def get_instance(self, user_id):
        """根据user_id哈希分配AI实例"""
        instance_id = hash(user_id) % len(self.pool)
        return self.pool[instance_id]
    
    async def handle_call(self, user_id, audio_stream):
        instance = await self.get_instance(user_id)
        # 加载用户配置（商家信息、防骚扰规则）
        user_config = await load_user_config(user_id)
        # 处理通话
        return await instance.process(audio_stream, user_config)
```

**优势：**
- 100个AI实例可以服务5万用户
- 每个实例处理多个并发通话（通过异步IO）
- 用户配置动态加载，无需常驻内存

### 3.2 SIP Trunk并发费优化

**问题：** 2,500路并发 × 50元/路 = 125,000元/月（太贵！）

**方案：直连运营商SIP Trunk**

**传统SIP Trunk供应商（容联云、融云）：**
- 他们也是从运营商批发的
- 加价率：100-200%

**直连运营商（中国电信/联通企业SIP）：**
- 并发费：20-30元/路/月
- 需要企业资质（营业执照、ICP备案）
- 最小采购量：100路起

**成本对比：**
```
容联云：2,500路 × 50元 = 125,000元/月
直连电信：2,500路 × 25元 = 62,500元/月
节省：62,500元/月
```

**如何对接：**
1. 联系中国电信/联通企业客户经理
2. 提交资质（营业执照、ICP备案、业务说明）
3. 签订SIP Trunk服务协议
4. 获取SIP账号和接入地址
5. 在FreeSWITCH配置网关

## 六、技术风险与应对

### 6.1 FreeSWITCH集群单点故障

**风险：** 某台FreeSWITCH宕机，影响500路通话

**应对：**
- Kamailio实时健康检查（每5秒ping一次）
- 故障节点自动摘除
- 通话自动转移到其他节点
- 主备双机热备（关键节点）

### 6.2 171号码被大量标记为骚扰

**风险：** 用户手机显示"骚扰电话"，影响接听率

**应对：**
1. **号码认证机制：** 首次拨打后自动发短信认证
2. **号码轮换：** 定期更换被标记的号码
3. **白名单申请：** 向腾讯手机管家、360等平台申请白名单
4. **长期方案：** 申请95号段（企业专属，不会被标记）

### 6.3 运营商限制高频呼入

**风险：** 单个号码日呼入超过500次，被运营商限制

**应对：**
- 监控每个号码的日呼入量
- 超过阈值自动切换到备用号码
- 与运营商沟通，说明业务场景，申请白名单
