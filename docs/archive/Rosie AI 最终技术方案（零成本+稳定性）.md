## 二、零成本技术栈（月成本 < 5元）

### 2.1 通信层（成本：5元/月）

**方案：4G USB Dongle + 保号卡**

- **硬件：** 华为4G上网卡（支持语音AT指令，闲鱼50元一次性投入）
- **SIM卡：** 电信/联通保号套餐（5元/月，接听免费）
- **接入方式：** 商家主号设置呼叫转移到保号卡号码
- **技术实现：** 
  - Go/Rust守护进程通过串口发送AT指令接听电话
  - 提取PCM音频流通过WebSocket转发到处理服务器

**备选方案：** 闲置安卓机 + Tasker自动接听（更简单但稳定性略低）

### 2.2 语音识别（STT）- 完全免费

**方案：阿里开源 FunASR / SenseVoice**

- **部署方式：** Docker本地部署（CPU服务器即可）
- **延迟：** 流式识别，200-400ms
- **优势：** 
  - 中文识别准确率高
  - 支持方言和口音
  - 无API调用费用
  - 可离线运行

**防骚扰前置过滤：**
```python
# 前5秒关键词黑名单
SPAM_KEYWORDS = [
    "贷款", "POS机", "发票", "代开", 
    "老板在吗", "了解一下", "商铺", 
    "财务公司", "税务优化"
]

# 接通后立即启动STT，检测前5秒
if detect_keywords(first_5_seconds, SPAM_KEYWORDS):
    hangup()  # 直接挂断，不消耗后续算力
```

### 2.3 对话大脑（LLM）- 接近免费

**方案A（推荐）：DeepSeek-V3 API**

- **成本：** 1元 = 100万input tokens（一通3分钟电话约500 tokens）
- **月成本估算：** 单商家月均100通电话 = 0.05元
- **优势：** 
  - 中文理解极强
  - 支持Function Calling（预约功能必需）
  - API稳定性高
  - 几乎等于免费

**方案B（极客备选）：本地部署Qwen2-7B**

- **硬件要求：** 16GB显存GPU或32GB内存CPU
- **优势：** 完全零成本，数据不出服务器
- **劣势：** 需要自己维护模型更新

**推荐：** 先用DeepSeek API快速验证，后期用户量大再考虑本地部署

### 2.4 语音合成（TTS）- 完全免费

**方案：微软Edge TTS（开源逆向）**

- **成本：** 0元（无额度限制）
- **音质：** 晓晓(Xiaoxiao)声音自然度极高
- **延迟优化：** 
  - 固定话术提前生成缓存（如"您好，这里是XX店"）
  - 动态回复实时调用Edge TTS
  - 平均延迟300-500ms

**Python实现：**
```python
import edge_tts

async def text_to_speech(text):
    communicate = edge_tts.Communicate(text, "zh-CN-XiaoxiaoNeural")
    await communicate.save("output.mp3")
```

### 2.5 后端逻辑（成本：0元）

**技术栈：** Python FastAPI / Go Gin

**数据存储：** 
- **方案A：** SQLite本地文件数据库（单商家场景足够）
- **方案B：** PostgreSQL（多商家扩展）

**通知推送：** 
- 企业微信群机器人Webhook（免费）
- 钉钉群机器人Webhook（免费）
- 飞书Webhook（免费）

**预约日历：**
- 不对接第三方日历API
- 直接在数据库维护时间槽位
- 通过Webhook推送到商家微信/钉钉

##四、防骚扰机制（核心竞争力）

### 4.1 三层过滤体系

**第一层：号码黑名单（接通前）**
- 维护已知营销号码库
- 检测到直接拒接

**第二层：关键词识别（前5秒）**
```python
# 高危词汇立即挂断
INSTANT_HANGUP = ["贷款", "POS机", "代开发票"]

# 可疑词汇进入观察模式
SUSPICIOUS = ["老板在吗", "了解一下", "有个事"]
```

**第三层：对话行为分析（5-15秒）**
- 检测是否为录音播放（背景噪音特征）
- 检测是否为机器人（语速、停顿模式）
- 检测是否为话术式推销（固定句式）

### 4.2 挂断后处理
```python
if is_spam_call:
    # 记录到黑名单
    blacklist.add(caller_number)
    # 不消耗LLM token
    # 不推送通知给商家
    # 仅记录日志供后续分析
```
